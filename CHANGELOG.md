# Changelog

## 1.1.0 - September 25, 2026

- Gave Boojie Cardinal Points a new black-and-pink **BCP** icon everywhere it appears.
- Added a dedicated settings window that matches the rest of the Boojie addon family.
- Put the current version and the `/bcp` shortcut right at the top of the window.
- Added a minimap-button toggle and proper LibDataBroker and LibDBIcon support, so WindTools can gather the button into its minimap button bar.
- Kept the Blizzard AddOns panel as a simple, tidy launcher for the full settings window.
- Preserved existing letter sizes, colors, outlines, and individual compass-point positions.
